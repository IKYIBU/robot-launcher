# 広告導入計画（v22には広告コードなし）

## 現状
本作に広告SDKやトラッキング用SDKは入っていません。ゲーム内の広告予約枠はダミー表示です。閲覧数や広告収益の追跡もしていません。

## 将来の進め方
1. ゲームを公開し、品質・運営者情報・正式なプライバシーポリシー・問い合わせ先を整える。
2. 選択した広告サービスの利用規約・対象サイト要件・Cookie/同意・未成年ユーザー対応を確認。
3. Google H5ゲーム広告を選ぶなら、**承認済みAdSenseアカウント**に加え、H5ゲーム広告への別途申請が必要。承認保証なし。
4. 正式承認後、配信事業者の指定する導入方法で追加。ゲーム操作・発射・クリア演出を邪魔せず、ユーザーの誤タップを招かない配置にする。
5. 本番と別のテスト環境で検証し、ポリシー・表示・プライバシー対応完了後に有効化する。

Google公式: https://support.google.com/adsense/answer/1705831?hl=ja
Google開発者向け: https://developers.google.com/ad-placement/docs/signup?hl=ja

**禁止:** 審査を通っていない広告タグを仮のIDで設置したり、実収益化を完了と報告したりしない。
